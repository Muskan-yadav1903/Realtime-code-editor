Build Real-time code editor using React, Node Js, Express, Web sockets

start the project 
1. yarn start -> start project ( frontend )
2. yarn server:dev -> ( backend )


packages install using yarn 
1. yarn add react-router-dom 
2. yarn add uuid -> package that create a unique id for every new room 
3. yarn add react-hot-toast -> it shows the new notification when the user create a new room  
4. yarn add react-avatar -> for show the username avatar
5. yarn add codemirror -> code editor ko use karne ke liye realtime code karne ke liye 
6. yarn add express socket.io 
7. yarn add socket.io-client -> client ka connection karne ke liye
8. yarn add -D nodemon
